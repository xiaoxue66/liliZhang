# ZHANG Lili / 张丽丽

Bilingual artist–researcher portfolio. Static HTML, CSS and JavaScript for GitHub Pages.

## Update content

Edit `content.js`. English and Chinese text uses `en` and `zh` fields. `works` contains creative works; `researchProjects` contains research project details. `publications`, `underReview`, `conferences` and `theses` are separate lists. Put artwork images in `assets/`. Video blocks accept YouTube, Vimeo, Bilibili and supported official EHM video links. No build step is required.

## Hosting

Use Settings → Pages → Deploy from a branch → main → /(root). `.nojekyll` serves these static files directly.

Personal CV source files and private application materials are not part of this repository.
